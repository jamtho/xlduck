XlDuck · Windows x64 · Public preview setup

SQL research in Excel

Install the add-in once. Excel loads it on normal startup; your workbooks stay ordinary Excel files.

This development package is unsigned. Only use a download whose origin you trust. If Windows marks it as blocked, review the ZIP's Properties → Unblock before extracting it again. Setup does not change Excel's Trust Center or unblock files.

1. Check the prerequisites

  • 64-bit desktop Excel on Windows x64 (Microsoft 365 or Excel 2021/2024).
  • .NET 10 Desktop Runtime, Windows x64 — choose “Run apps”; no SDK needed.
  • WebView2 Evergreen Runtime for previews. Many machines already have it.

2. Run Install.cmd

Save your work and close Excel yourself. In the extracted package, double-click Install.cmd. It checks the package and prerequisites, copies the complete add-in into your local application-data folder, and registers it for Excel startup. No administrator rights are needed for XlDuck itself.

Open Excel normally and enter these in separate cells:

=DuckVersion()
=DuckQueryOutScalar("SELECT 42")

The query should settle to 42. For a chart, enter the following, select its handle and choose XlDuck → Preview Pane:

=DuckPlot(DuckQuery("SELECT range AS n FROM range(5)"),"line","x","n","y","n")

Close Excel normally and reopen it to check startup loading. A previously registered development copy must be unchecked in Excel's Add-ins dialog before installation.

3. Set up your agent (optional)

Ready to explore? Open the included research demo workbook and save a working copy under Documents. It uses synthetic data, with no credentials or external sources. Select a chart handle and open the preview pane; edit the amber inputs.

XlDuck runs SQL; your AI provider supplies the agent. The same tiny bootstrap skill ZIP tells either agent to read guidance from the installed add-in. Detailed instructions update with XlDuck.

OpenAI's Excel sidebar: in an eligible ChatGPT workspace, open Plugins → Skills → Create → Upload from your computer and upload agent/xlduck-skill.zip. Then look for XlDuck in the Excel sidebar's + skill picker or @ menu. Upload availability depends on your plan and workspace; do not assume a personal account has this option. Provider instructions.

Claude for Excel: in Claude, open Customize → Skills → + → Create skill → Upload a skill. Upload the same ZIP and enable it. Use the same Claude account in Excel and look for /xlduck. Code execution and organization permissions must allow skills. Provider instructions. Claude's XlDuck execution path still needs a live compatibility trial.

Codex desktop controlling Excel: double-click Install Codex Skill.cmd. This installs only the local skill under %USERPROFILE%\.agents\skills\xlduck; it does not install a skill into the separate Excel sidebar. It preserves any different existing skill. Start a new Codex chat, select XlDuck, and connect the open workbook through the signed-in OpenAI Excel add-in.

If your provider cannot install a skill, paste this starting prompt:

Use XlDuck. Read DuckHelp() and DuckHelp("workflow") from the loaded add-in, then follow that guidance. Use formula evaluation without editing cells if available.

Verify discovery: in a fresh agent conversation, select the installed skill and ask it to read XlDuck's help and evaluate SELECT 42 AS answer using the documented exploration interface. It should return 42, polling if needed. If its tools cannot evaluate without cells, it should explain that and use an agreed scratch area. Installing the skill does not add Office.js capabilities.

Upgrade, recover and remove

Close Excel and run Install.cmd from a newer package to upgrade. The preceding installation remains available: run Rollback.cmd to switch back. Uninstall.cmd removes XlDuck's startup registration, leaving recovery copies and user data alone. There is no automatic updater or Windows Apps entry yet.

For manual registration, troubleshooting, file locations and full removal, see the installation guide. For agent execution details, see agent integration.
